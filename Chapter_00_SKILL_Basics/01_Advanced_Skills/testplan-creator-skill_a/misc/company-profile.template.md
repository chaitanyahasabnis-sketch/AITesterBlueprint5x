# Company Profile (template)

Fill this in, save it as your own profile, and give it to the test-plan skill as `[COMPANY PROFILE]`.
Leave anything you don't know as `[Not supplied]`. The skill will not guess.

| Field | Value |
|-------|-------|
| Company name | [COMPANY NAME] |
| Product / application | [PRODUCT NAME] |
| Product URL | [URL] |
| Domain / industry | [e.g. E-commerce, Banking, SaaS] |
| What the product does (1–2 lines) | [SHORT DESCRIPTION] |
| Users | [PRIMARY USERS] |
| Logo file (optional) | [PATH, e.g. misc/logo.png] |
| Notes for test plans (optional) | [e.g. compliance needs, supported browsers] |
