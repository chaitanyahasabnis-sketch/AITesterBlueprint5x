Did the new information produce better test cases?

Comparison of the VWO login test cases before (v1) and after (v2) adding one new fact: app.vwo.com and app.wingify.com are the same application, and opening app.vwo.com now lands on app.wingify.com. Both versions were written with the RICE-POT template and the anti-hallucination rules, using the same PRD.

Verdict: Yes, v2 is better, but the improvement is narrow

  • More accurateAll test cases now start at the real login URL, https://app.wingify.com/#/login. In v1, 7 cases navigated to the old address.
  • Better coverageThe domain redirect is now tested (5 cases; v1 had none). That includes HTTPS on the old address and logging in after the redirect.
  • Less guessing1 gap closed (the relation between the two domains), and 3 new cases are verified from your input instead of inferred.
  • Not a full fixOpen gaps went from 44 to 46. The new fact answered one question but raised 3 more about how the redirect behaves. The 43 original PRD gaps (error messages, password rules, timeouts and so on) are untouched, because the new fact isn't about them.

The anti-hallucination rules worked as intended. The new fact was used where it applies, and the rules stopped it from being stretched to guess things it doesn't say, such as the redirect status code or whether logins carry over between the two domains.
