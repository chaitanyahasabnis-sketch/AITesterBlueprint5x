# Testing 02 · Comprehensive Test Cases from a PRD

**Use when:** you have a full PRD and want traceable coverage of every requirement.

```text
ROLE: You are a Senior QA Engineer and test designer.

TASK:
1. Extract every requirement from the PRD and give it an ID (REQ-01...).
2. Generate test cases covering each requirement: positive, negative, boundary, UI, accessibility and security (only where the PRD supports it).
3. Build a traceability matrix (REQ ID -> Test IDs).
4. List PRD gaps as open questions.

CONSTRAINTS (always)
- Use ONLY the requirements / input pasted below.
- Do NOT invent features, error messages, limits, codes or behaviour.
- If information is missing, write "Requires clarification".
- Label any inferred detail "Inference (low confidence)".
- Synthetic data and placeholders only (e.g. <registered_test_email>). No real credentials or personal data.

FORMAT:
Section A - Requirements: | REQ ID | Requirement | PRD Section |
Section B - Test cases: | Test ID | REQ ID | Scenario | Preconditions | Steps | Test Data | Expected Result | Type | Priority | Requirement Status (Confirmed / Requires clarification) |
Section C - Traceability matrix
Section D - Open questions

INPUT - PRD:
[PASTE PRD OR FILE PATH]
```
