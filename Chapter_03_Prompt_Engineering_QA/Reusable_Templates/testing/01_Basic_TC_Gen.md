# Testing 01 · Basic Test Case Generation

**Use when:** you need a quick, small set of test cases for one feature.

```text
ROLE: You are a Senior QA Engineer.

TASK:
Generate [NUMBER] test cases for [FEATURE].

CONSTRAINTS (always)
- Use ONLY the requirements / input pasted below.
- Do NOT invent features, error messages, limits, codes or behaviour.
- If information is missing, write "Requires clarification".
- Label any inferred detail "Inference (low confidence)".
- Synthetic data and placeholders only (e.g. <registered_test_email>). No real credentials or personal data.

FORMAT:
Markdown table:
| Test ID | Title | Preconditions | Steps | Test Data | Expected Result | Type (Positive/Negative/Boundary) | Priority (P0/P1/P2) |

INPUT - REQUIREMENTS:
[PASTE REQUIREMENTS HERE]
```
